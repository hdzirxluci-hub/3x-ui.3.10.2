# 3x-ui روی Railway

**پنل 3x-ui نسخه `v3.9.0` — با یک پورت، روی یک سرویس Railway**

بدون VPS، بدون دامنه، بدون Cloudflare. لینک ساب می‌گیری، روی گوشی کار می‌کند.

## ⚡ راه‌اندازی

### ۱. ریپو را انتخاب کن

همین ریپو روی اکانت خودت است؛ لازم نیست جایی کپی بگیری.

### ۲. روی Railway دیپلوی کن

**New Project** → **Deploy from GitHub repo** → همین ریپو.

> دکمه‌ی بالا فقط درِ Railway را باز می‌کند و **ریپو را خودش انتخاب
> نمی‌کند**. برای اینکه تک‌کلیک واقعی شود و ریپو از پیش انتخاب‌شده باشد،
> سازنده باید یک Railway Template منتشر کند (پایین صفحه توضیح داده شده).

### ۳. دو تا چیز را دستی ست کن

این دو را نمی‌شود از داخل کد ست کرد:

| کجا | چه کار |
|---|---|
| **Settings → Volumes → Add volume** | Mount Path را بگذار `/etc/x-ui` |
| **Settings → Networking → Generate Domain** | بعد حتماً **Redeploy** بزن |

> **Volume** را نگذاری، هر دیپلوی کلاینت‌ها و رمزت را پاک می‌کند.
> **Redeploy** نزنی، لینک‌ها با دامنه‌ی خالی ساخته می‌شوند.

### ۴. تمام

لاگ دیپلوی را باز کن. آدرس پنل و لینک ساب همان‌جا چاپ می‌شود:

```
Panel          https://<دامنه‌ی‌تو>.up.railway.app/panel/
Subscription   https://<دامنه‌ی‌تو>.up.railway.app/sub/PABLO
```

## 👥 کاربر اضافه کردن

لازم نیست اینباند بسازی یا لینک تازه بدهی:

1. پنل ← **Clients** ← **Add Client**
2. یک **Email** بده (مثلاً `ali`)
3. در **Sub ID** دقیقاً `PABLO` را بنویس
4. **تیک ورودی را بزن** ← ذخیره

کانفیگش خودش به **همان لینک ساب** اضافه می‌شود. لینک جدیدی در کار نیست.

> ⚠️ دو تا چیز که پنل رد می‌کند:
> - **فاصله** در اسم — `Ali Reza` قبول نمی‌شود، `ali_reza` یا `علیرضا` قبول است
> - **تیک نزدن اینباند** — `at least one inbound is required`

## 📱 لینک

این را بده به هر کسی که می‌خواهد وصل شود:

```
https://<دامنه‌ی‌تو>.up.railway.app/sub/PABLO
```

در **مرورگر** باز کنی، صفحه‌ی ساب می‌آید. در **v2rayNG / Streisand / v2box**
وارد کنی، کانفیگ خام می‌گیرد. یک آدرس، دو رفتار — خود پنل تشخیص می‌دهد چه
کسی دارد می‌پرسد.

---

## ⚠️ اگه کار نکرد

| مشکل | علت |
|---|---|
| لینک‌ها خالی یا با دامنه‌ی خالی | بعد از Generate Domain **Redeploy** نزدی |
| هر دیپلوی کلاینت‌ها می‌پرد | **Volume** با مسیر `/etc/x-ui` اضافه نکردی |
| `v2box` می‌گوید «شکست» | برای کلاینت **سقف حجم** نگذاشتی. پنل ← کلاینت‌ها ← ویرایش |
| صفحه‌ی ساب سفید است | دامنه درست نیست؛ `PUBLIC_HOST` را دستی بگذار |
| کلاینت «منقضی» نشان داده می‌شود | تاریخ انقضا را دوباره ست کن؛ `TZ` پیش‌فرض `Asia/Tehran` است |

## 🎨 برند

اسم برند پیش‌فرض `PABLO` است. برای عوض کردنش، در Railway Variables:

```
BRAND=اسم_خودت
```

همین. عنوان تب، صفحه‌ی ورود، سایدبار، اسم ورودی و اسم کانفیگ‌ها همه عوض
می‌شوند. **فونت و چیدمان دست نمی‌خورد.**

متن‌های صفحه‌ی ساب هم قابل تغییرند:

| متغیر | پیش‌فرض |
|---|---|
| `SUB_TITLE` | `PABLO` |
| `SUB_ANNOUNCE` | `این پنل توسط Pablo ساخته شده` |
| `SUB_SUPPORT_URL` | `t.me/poll_o0` |

بقیه‌ی متغیرها (`PANEL_PATH`، `TUNNEL_PATH`، `TRANSPORT`، `TZ` و…) همگی
پیش‌فرضِ کار‌کننده دارند — دست‌زدن بهشان لازم نیست.

## 🧩 چه چیزی داخلش هست

Railway به هر سرویس **یک پورت** می‌دهد و TLS را خودش در لبه انجام می‌دهد.
پنل ۲۰۵۳ می‌خواهد، سرویس ساب ۲۰۹۶ و Xray پورت خودش را — پس هر سه روی
`127.0.0.1` می‌نشینند و nginx بر اساس مسیر URL جداشان می‌کند:

```
client ──https──▶ Railway edge (TLS) ──http──▶ nginx :$PORT
   ├─ /healthz            → 200
   ├─ /panel/…            → پنل        :2053
   ├─ /sub  و  /sub/…     → ساب        :2097 ─▶ :2096
   ├─ /ws                 → Xray       :10085
   └─ /                   → 404
```

| فایل | کار |
|---|---|
| `Dockerfile` | دبیان + باینری رسمی `x-ui v3.9.0` + nginx |
| `entrypoint.sh` | تنظیم‌ها، ساخت اینباند، بالا آوردن سرویس‌ها |
| `nginx.conf.template` | تفکیک مسیرها + برند روی پنل |
| `subserver.py` | سازگار کردن هدرها با اپ‌ها |
| `railway.json` | healthcheck و سیاست ری‌استارت |

**نکته:** صفحه‌ی ساب **همان صفحه‌ی پیش‌فرض خود 3x-ui است**، نه یک صفحه‌ی
دستی‌ساز. فقط سه فیلد برند رویش می‌نشیند.

**نکته‌ی دوم:** وقتی کلاینت سقف حجم ندارد، 3x-ui هدر `Subscription-Userinfo`
را با `total=0` می‌فرستد (`internal/sub/calendar_expire.go` هیچ شرطی ندارد).
v2box با این هدر «شکست» می‌زد، با اینکه خود کانفیگ‌ها سالم رسیده بودند.
forwarder آن هدر را در این حالت نمی‌فرستد. سقف حجم که بگذاری، هدر با عدد
واقعی برمی‌گردد.

## 🔧 برای نگهدارنده: تک‌کلیک واقعی کردن دکمه

دکمه‌ی Deploy برای اینکه ریپو را از پیش انتخاب‌شده باز کند، به یک **کد
template** نیاز دارد. آن کد فقط از اکانت Railway سازنده ساخته می‌شود:

1. پروژه را یک بار کامل بالا بیاور (Volume و Generate Domain ست شده باشد)
2. در Railway: سرویس ← **⋮** ← **Generate Template**
3. Template را **Publish** کن
4. لینکی مثل `railway.com/new/template/AbCdEf` می‌گیری — همان `AbCdEf` کد است
5. در خط دکمه‌ی بالای README، `https://railway.com/new` را با
   `https://railway.com/new/template/AbCdEf` عوض کن
